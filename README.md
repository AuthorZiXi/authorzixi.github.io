## 项目

### 🎮 数桥 · Hashiwokakero

一个基于 Canvas 的数桥逻辑解谜游戏，支持 PWA 离线安装。

- 玩法页：<https://authorzixi.github.io/hashi/>
- 源码目录：[`hashi/`](./hashi)
- [隐私政策](https://authorzixi.github.io/hashi/privacy.html)

技术栈：原生 HTML / CSS / ES Modules，无构建步骤。
支持深色 / 浅色主题、拖拽平移、高分屏渲染。

## 本地开发

仓库根目录下启动任意静态服务器即可，例如：

```bash
python -m http.server 8080
# or
npx serve # node
```
