隐私策略 · Privacy Policy

最后更新：2026 年 10 月 5 日

1. 我们收集哪些信息

SaveData Chapter 不收集、不存储、不传输任何可识别个人身份的信息。

2. 本地文件操作

本应用是一个纯本地工具。所有操作都在你的设备上完成，包括读取和写入你选择的游戏存档文件夹、管理章节数据、以及保存本地配置文件。这些操作完全在本地进行，不涉及任何网络传输。

3. 本地存储

应用使用本地文件保存以下数据：

  • 配置文件（路径列表、主题、排除规则等）
  • 章节数据（保存在游戏存档目录下的 .savedata 文件夹）
  • 章节备注（meta.json）

这些数据仅保存在你的设备本地，不会上传到任何服务器。

4. 网络请求

应用本身不向任何第三方服务器发送数据，不联网，不进行任何形式的网络通信。

5. 第三方服务

本应用不集成任何第三方分析、广告或追踪服务。

6. 儿童隐私

本应用不会收集任何用户数据，因此不会收集儿童的个人信息。

7. 权限说明

Windows 版本通过 Microsoft Edge WebView2 承载应用界面，声明的 runFullTrust 权限仅用于运行应用本体以及读写用户明确选择的文件夹，不涉及任何个人信息的访问或传输。

8. 变更

如隐私策略有更新，将在本页面公布。

9. 联系方式

如有疑问，请通过 GitHub 联系。

Privacy Policy (English)

Last updated: October 5, 2026

SaveData Chapter does not collect, store, or transmit any personally identifiable information.

This is a fully local tool. All operations happen on your device, including reading and writing files in game save folders that you explicitly select, managing chapter data, and saving local configuration. No network transmission is involved.

The app does not connect to the network and does not send any data to third-party servers.

The app does not integrate any third-party analytics, advertising, or tracking services.

The Windows version uses Microsoft Edge WebView2 to host its UI. The declared runFullTrust capability is only used to run the application itself and to read/write folders that the user explicitly chooses. It does not access or transmit any personal information.

For questions, please contact via GitHub.
